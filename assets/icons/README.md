# Icons

Hairline, monochrome SVGs that inherit `currentColor`. They match the site’s 1px rules, square terminals, and black/white palette.

| File | Use |
| --- | --- |
| `github.svg` | GitHub mark |
| `mail.svg` | Envelope |
| `external.svg` | Outbound link |
| `arrow.svg` | Right arrow |
| `menu.svg` | Mobile nav open |
| `close.svg` | Mobile nav close |
| `cube.svg` | 3x3 cube face |
| `code.svg` | Chevrons / slash |
| `chip.svg` | Microcontroller |
| `sprite.svg` | Combined symbol sheet |

The live page uses the inline sprite in `index.html` so `currentColor` works on both the black canvas and the inverted cubing band.
